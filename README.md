## Denarii Dolor

Personal Budget and Expense Tracker Android app scaffolded with:

- Kotlin + MVVM + Repository pattern
- Hilt dependency injection
- Room database (transactions, categories, budgets, accounts)
- Transaction polymorphism (`Transaction`, `Expense`, `Income`, `Transfer`)
- Search filters (description/category/amount/date)
- Monthly report generation with CSV output
- PIN login with encrypted local preferences and biometric capability checks
- Dashboard, add transaction, search, and report UI foundations with bottom navigation + FAB
